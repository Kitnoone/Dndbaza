# Источники и границы выгрузки

В репозиторий входит полный текст приложенного файла `12 круг — исправлено.docx`, его неизменённая копия, поисковые фрагменты, структурированный канон и доступные резюме обсуждений проекта.

Здесь нет дословной истории всех старых веток ChatGPT: текущая рабочая среда не предоставляет такой архив. Чтобы добавить её без потерь, нужен официальный экспорт данных ChatGPT; его затем можно обработать тем же конвейером.

Поля со статусом `secret_canon` содержат мастерскую информацию и не предназначены для игроков.
