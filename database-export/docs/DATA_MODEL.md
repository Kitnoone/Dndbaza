# Модель данных

- `sources` — исходные документы и контрольные суммы.
- `chunks` / `chunks_fts` — полный текст, разбитый на перекрывающиеся фрагменты для поиска и RAG.
- `entities` — персонажи, места, фракции и артефакты.
- `relationships` — направленные связи между сущностями.
- `timeline` — упорядоченные события.
- `canon_facts` — утверждённые и секретные факты.
- `conversation_summaries` — доступные резюме тематических обсуждений, не дословный экспорт сообщений.

JSON и JSONL являются переносимым источником истины. Снимок SQLite хранится в `data/dnd_12_circle.sqlite3.xz`; его можно распаковать командой `python scripts/unpack_database.py` или пересобрать командой `python scripts/build_database.py`.
