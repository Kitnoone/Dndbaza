# Dndbaza: база кампании «Двенадцатый круг»

Это переносимая база знаний по кампании: полный исходный DOCX, извлечённый текст, структурированный канон, справочники и SQLite с полнотекстовым поиском.

## Состав

- страниц в исходном DOCX: 122;
- содержательных абзацев: 2691; слов: 48100;
- 294 поисковых фрагментов с перекрытием;
- 27 основных и 14 дополнительных персонажей;
- 3 артефакта, 10 локаций и 9 фракций;
- сжатый снимок SQLite, JSON, JSONL, SQL-схема и скрипты поиска/пересборки.

## Быстрый поиск

```bash
python scripts/search_database.py "Серафина"
python scripts/search_database.py '"Седьмая струна"'
```

При первом поиске снимок SQLite автоматически распакуется. Для ручной распаковки используйте `python scripts/unpack_database.py`.

## Основные файлы

- `sources/12-круг-исправлено.docx` — неизменённый исходник;
- `docs/12-circle-full-text.md` — полный читаемый текст;
- `data/dnd_12_circle.sqlite3.xz` — сжатый снимок готовой базы;
- `data/chunks.jsonl` — фрагменты для RAG/ИИ;
- `data/entities.json` — сущности;
- `data/name_corrections.json` — актуальные исправления имён;
- `docs/SOURCES_AND_LIMITS.md` — точные границы выгрузки.

Мастерские секреты находятся в базе вместе с остальным каноном. Не публикуйте эту ветку игрокам без отдельной очистки.
