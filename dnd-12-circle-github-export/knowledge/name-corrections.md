# Правки имён и связей

- Использовать **Друселия**, не «Брюссель». финальное имя распорядительницы гонки.
- Использовать **Амдир**, не «Дир». зафиксированная правка.
- Использовать **Серафина Ламандар**, не «Серафина Аламондар». каноничная фамилия; ранний вариант сохранён в документе.
- Использовать **Макалай Харроу — прежняя реинкарнация Серафины**, не «отдельная несвязанная сущность». одна душа.
- Использовать **Анна — дочь Стейна и Катран**, не «Анна — дочь Круга». исправленная связь.
- Использовать **Коркош — дочь Круга**, не «Коркош — дочь Стейна». исправленная связь.
- Использовать **Отто Гагенс**, не «другие варианты». зафиксированное имя.
