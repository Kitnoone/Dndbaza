# Крууг

- **ID:** `kruug`
- **Статус:** канон документа
- **Тип:** старый эльф-друид
- **Роль:** хранитель рощи
- **Псевдонимы:** нет

## Каноничные факты

- Сдерживает Сильвану и перекрёсток фей.
- Его жизнь вплетена в корни рощи.
- Может быть убит только зверем.
- Для ритуала нужны Волшебный боб, веточка омелы, Посох Лесоземья и Книга Джербала.

## Внешность

- старый эльф
- длинные седые волосы

- враг → `sylvana`
- семейная связь → `korkosh`
