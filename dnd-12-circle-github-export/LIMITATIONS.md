# Ограничения выгрузки

Сборка содержит всё, к чему текущая сессия имела доступ: основной DOCX, извлечённый текст, проектный канон, структурированные сущности, доступные фрагменты обсуждений, SQLite и JSONL.

Она не является полным дословным экспортом всех старых веток ChatGPT, потому что одна ветка не получает автоматический полный доступ к другим веткам проекта. Для дополнения используйте официальный экспорт данных и `scripts/import_chatgpt_export.py`.
